# Нагадай — Android MVP

Нативний Android-застосунок українською: ручне додавання одноразових подій, локальне збереження, точний будильник, повноекранне нагадування, завершення й відкладання на 5 хвилин. Обліковий запис та інтернет не потрібні.

## Завантаження APK з телефона

1. Відкрийте вкладку [Actions](https://github.com/ut8uu/persistent-reminder-android/actions/workflows/android.yml).
2. Виберіть останній успішний запуск **Build Android APK** (зелена позначка).
3. Унизу, в **Artifacts**, завантажте **nagadai-debug-apk** (потрібно увійти в GitHub).
4. Розпакуйте ZIP і відкрийте `app-debug.apk`. Дозвольте встановлення з цього джерела, якщо Android попросить.
5. Відкрийте «Нагадай» та надайте потрібні дозволи через «Налаштувати дозволи».

Збірка запускається після змін у `main`, у pull request та вручну через **Run workflow**. APK і звіт Android Lint зберігаються 7 днів. Якщо артефакт застарів, запустіть workflow повторно. Використовується стандартний Linux runner.

Це тестовий debug APK, підписаний автоматичним ключем збірки. Ключ між запусками не зберігається: для встановлення наступної збірки може знадобитися видалити попередню версію, що також видалить локальні події. Для стабільних оновлень потрібен постійний ключ підпису.

## Збірка

1. Встановіть актуальний Android Studio, Android SDK Platform 35, JDK 17 або новіший.
2. Відкрийте папку Reminder як Gradle-проєкт. Використайте Gradle 8.9 у налаштуваннях Gradle (wrapper у цьому архіві відсутній).
3. Виконайте Gradle Sync і Build → Build APK(s), або з установленим Gradle 8.9: `gradle :app:assembleDebug`.
4. APK буде в `app/build/outputs/apk/debug/app-debug.apk`.
5. Встановіть на Android 8.0+ і через кнопку «Налаштувати дозволи» послідовно надайте сповіщення, точні будильники й повноекранні сповіщення (на відповідних версіях Android).

## Поведінка

Події зберігаються лише на пристрої. «Виконано» видаляє подію. «Відкласти» змінює час на поточний + 5 хвилин. Після перезавантаження майбутні нагадування плануються знову, пропущені спрацьовують після завантаження. Час збережено як абсолютний момент; зміна часового поясу змінює відображення місцевого часу.

Звук використовує системний канал будильників і FLAG_INSISTENT. Повноекранний показ запитується через fullScreenIntent: на розблокованому телефоні Android може показати спливаюче сповіщення. Гучність, тривалість звуку, «Не турбувати», налаштування каналу та обмеження виробника впливають на сигнал. Беззвучний канал не вмикається програмою примусово. Закриття екрана кнопкою «Назад» не завершує подію: дії залишаються у сповіщенні.

## Ручна перевірка на пристрої

- Відхилити кожен дозвіл: програма пояснює необхідність налаштування й не дозволяє додати подію без потрібних дозволів.
- Додати подію через 2 хвилини, заблокувати телефон: перевірити сигнал, вібрацію й повноекранний показ.
- Натиснути «Виконано»: сигнал припиняється, подія зникає.
- Відкласти з екрана і зі сповіщення: сигнал припиняється і повторюється через 5 хвилин.
- Видалити майбутню подію: будильник не спрацьовує.
- Перезавантажити телефон з майбутньою подією: будильник відновлюється.
- Перевірити дві одночасні події, розблокований екран, «Не турбувати», відсутність дозволу на весь екран і відкликання дозволу на точні будильники.

## Статус

Початковий вихідний код, без зовнішніх бібліотек. GitHub Actions налаштований на складання debug APK і Android Lint. Перевірки на фізичному пристрої ще не виконано. Це прототип, не перевірений для критичних нагадувань. Редагування подій, повторення, синхронізація календаря й вибір мелодії поки не реалізовані.
